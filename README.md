# satellite1105

**Web / Backend Development · AI-driven Development · Automation**

ゲームの企画・運営で培った課題整理やKPI分析の経験と、Web開発・業務自動化の技術を組み合わせて、課題の発見から設計・実装・検証まで取り組んでいます。

PHPを中心としたWeb開発に加え、Pythonによるデータ処理やAPI連携、Claude Code・OpenAI Codexを活用した開発ワークフローの設計・改善にも取り組んでいます。

## 得意領域

- **Web / バックエンド開発** — PHP・Laravel、JavaScript、MySQLを使った機能開発・改善
- **業務自動化・データ活用** — Python、CSV・API連携、集計処理、KPI分析、定型業務の効率化
- **AI駆動開発** — 要件整理、タスク分割、AIへの実装委譲、テスト・レビュー、失敗時の再実行設計
- **企画・運営と開発の橋渡し** — ゲーム企画・運営の経験を生かした要件定義、数値分析、改善提案

## 開発で重視していること

1. **目的と完了条件を明確にすること** — 実装する機能だけでなく、何が改善されれば成功かを整理する。
2. **動作を確認できる形で残すこと** — テスト、再現手順、検証結果、未確認の範囲を区別する。
3. **運用・改善まで考えること** — エラー処理、保守性、作業の自動化を意識する。

Webシステム開発、業務改善・自動化、AIを活用した開発の実績や取り組みを、公開可能な範囲で順次追加していきます。
